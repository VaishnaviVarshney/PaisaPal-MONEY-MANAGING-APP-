# PaisaPal 💜 — Personal Finance Tracker

PaisaPal is a personal finance management web application that I built to make it easier to track daily expenses, manage a monthly budget, and keep track of savings goals.

The idea behind this project is simple: instead of keeping track of expenses manually, users can manage their financial activity in one place through a simple and easy-to-use dashboard.

## Features

* **Dashboard:** View your balance, total income, expenses, and savings summary.
* **Transaction Management:** Add, edit, delete, search, and filter income and expense records.
* **Monthly Budget:** Set a budget and keep track of spending.
* **Savings Goals:** Create savings goals and monitor progress.
* **Spending Insights:** Get basic insights based on recorded transactions.
* **Wishlist:** Save items you plan to buy along with their estimated prices.
* **Charts & Reports:** View spending categories and monthly income and expense trends.

## Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Java, Spring Boot
* **Database:** H2 Database
* **ORM:** Spring Data JPA
* **Charts:** Chart.js
* **Build Tool:** Maven

## How to Run the Project

1. Install Java JDK and Apache Maven.

2. Clone or download this repository.

3. Open the project folder in VS Code.

4. Open the terminal in the folder containing `pom.xml`.

5. Run the application:

   ```bash
   mvn spring-boot:run
   ```

6. Open `http://localhost:8080` in your browser.
